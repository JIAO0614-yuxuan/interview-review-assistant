# 面试复盘台 · 把失败的面试拆开看
> Slogan：面试翻车？先来这里“面壁”。

在传统的模拟面试中，候选人往往只能得到"还不错""继续加油"等无效反馈。**面壁**通过内置的"资深大厂面试官"系统提示词（System Prompt），能够精准识别面试对话中的逻辑漏洞、STAR 法则缺失及情商短板，并给出"毒舌"但极具建设性的优化重写方案。

> 单前端项目，零依赖、零后端。双击 `standalone.html` 即可演示，断网可用。

## 报告结构（每道题四段）

| 段落 | 内容 |
| --- | --- |
| 01 面试官到底在考什么 | 问题还原 + **潜台词分析**（一句话点破真实意图）+ 考官心里的打分锚点 |
| 02 你的回答诊断 | 亮点（只挑一句可验证的，没有就直说）+ 致命伤（逻辑漏洞 / 空话 / 无数据 / 未闭环，每条附原句证据与"他会怎么想"）+ 评分（x/100）+ 逐句拆解 |
| 03 满分回答示范 | 用**用户自己的事实**按 STAR 重写，只改表达不编数据；缺口处留〔待补〕占位 + 参考说法 + 优化解析（为什么这么改，逐条列出） |
| 04 预警：下一轮的追问 | 预测 2 个最可能被盘问的问题 + 一句话应对策略 + 他真正想确认什么 + 60 秒回答骨架 |

报告顶部还有：**复盘结论**（整体判词）、四个统计块、**失败归因**（本场面试最可能挂掉的三条原因）。

## 核心输入（同页平铺，无需切换）

- **候选人信息**：姓名、目标岗位、公司 / 团队、本场结果。姓名与岗位会从简历自动识别补全；岗位填「产品 / 运营」等非技术岗时，追问自动换成行为类问题，不再出现技术深挖。
- **简历 / 个人简介（可选）**：粘贴或上传 `.txt/.md`。粘贴后实时识别年限与技术栈（chips 展示），并提供两层校验：年限口径（含中文数字）与技能证据（简历写了但全场零提及的技术）。
- **面试记录（必填）**：粘贴文字稿，支持「面试官：/候选人：」「Q：/A：」、半角冒号、无标注整段；或用浏览器语音识别边说边转写（Chrome / Edge）。
- **实时预检**：输入时自动统计问答组数、字数、数据点、说话人标注状态，给出就绪度百分比与下一步建议；内容自动存草稿（localStorage），刷新不丢。
- **开始复盘**：固定在页面底部的操作条，支持 Ctrl / ⌘ + Enter。全部计算在浏览器本地完成，不上传任何内容。

## 诊断引擎能力（`assets/js/engine.js`）

- **意图识别**：9 类题型（技术深度 / 项目复盘 / 协作冲突 / 压力反思 / 动机 / 数据 / 推动力 / 自我介绍 / 通用），每题给出考察点、置信度与"高分回答应含的 4 个信号"。
- **句级 STAR 拆解**：每句标注 S/T/A/R 归属与判定，附质量标记（空泛评价、无数据支撑、口水词、模糊表述、主体是团队……）。
- **逻辑漏洞检测（8+ 类）**：
  - 跨单位矛盾：`从 220 毫秒降到 1.8 秒` 会被换算成 220ms→1800ms 并判定方向相反；
  - 数据自相矛盾、同一单位量级异常、结论无数据、评价代替事实、未闭环、结果无动作、「我们」吃掉个人贡献、答非所问、简历年限冲突、技能零证据等。
- **满分回答改写**：约 20 条措辞升级规则（换主语、动词升级、去模糊、去空泛、技术具体化……），空话直接删除；**不虚构任何数字**，缺失证据一律留〔待补〕。
- **追问生成**：缺口驱动（数据被质疑 / 贡献边界 / 未闭环）+ 题型驱动 + 技术话题深挖（Redis / 索引 / 并发 / 消息队列等 10 类），每条附考点、策略与回答骨架。

## 文件结构

```
index.html            入口页面
standalone.html       单文件打包版（node build.js 生成，比赛现场直接打开）
assets/
  css/style.css       全部视觉样式（科技蓝设计系统：#2563EB 主色 + 极浅蓝层次 + 中性灰阶）
  js/engine.js        诊断引擎（纯逻辑，无 DOM，可在 Node 中单测）
  js/app.js           渲染与交互层
build.js              打包脚本
```

## 使用

直接打开 `index.html`（或 `standalone.html`），点「载入示例」→「开始复盘」。支持 Ctrl/⌘ + Enter 提交，报告可一键复制为纯文本。

## 工程说明

- 引擎与渲染完全解耦：`window.InterviewEngine.buildReport(text, resume)` 返回结构化报告，`window.__interviewReview` 保留调试出口。
- 替换为真实大模型只需重写 `buildReport` 一处，报告结构不变。
- `node build.js` 将 CSS/JS 内联生成 `standalone.html`；构建时校验无残留外链。
